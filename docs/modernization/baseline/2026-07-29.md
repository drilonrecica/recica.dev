## Privacy and network inventory

Representative local browser audits confirmed:

- all observed application requests were same-origin;
- Tools JSON input/output did not enter request bodies or URLs;
- no user input/output entered localStorage, sessionStorage, IndexedDB, or
  Cache Storage;
- Labs and Recica made no unexpected external request;
- Tools persists only the harmless theme preference;
- the Device tool probes storage availability but does not retain probe data.

The HTML and Markdown previews use empty-sandbox `srcdoc` iframes. QR and
barcode exports use local canvas/SVG/blob download paths.

## Known baseline issues

- Recica lacks the full response-header policy present on Tools and Labs.
- Tools and Labs CSP currently require inline script permission.
- Tools and Labs derive canonicals from the request origin when configuration
  is missing or invalid.
- Tools emits FAQ structured data for questions not visibly rendered.
- Tools pages provide only short usage notes instead of the required content
  model and do not enforce a consistent UTF-8 input policy.
- Tools and Labs assign the current date to unchanged sitemap entries.
- Labs ships 42 font files totalling about 414 KiB.
- `labs/README.md` references planning files that are not present.
- Labs has no `.dockerignore`.
- A generated Playwright `.last-run.json` file was tracked under Recica.
